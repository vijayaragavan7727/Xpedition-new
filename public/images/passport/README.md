# Passport assets

These images were cut out of the prepared Xpedition Passport asset sheet ("Passport Book Assets", "Stamp Variations", "Evidence Icons", "Milestone / Achievement Stamps", "Background / Texture"). They keep the sheet's own transparency.

The sheet's sample data was **removed** so that nothing on the Passport shows fabricated learner results. The Passport UI writes the learner's real, evidence-derived values into these blank areas instead.

| Asset | What was removed |
|---|---|
| `stamp-*.png` | "Completed <date> / M <percent>%" |
| `milestone-level-up.png` | "LEVEL 4" |
| `milestone-streak.png` | "5 DAYS" |

`stamp-history.png` was drawn grey (a "locked" variant) on the sheet. It is recoloured brown so that History can be shown like any other subject once the learner has evidence in it.

Not used, because they state claims the application cannot support:
- "Top Performer" (implies a ranking against other learners);
- the sample learner identity/expedition pages (baked-in name, XP, dates and passport number).
